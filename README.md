# WPCV Quick Search

A CiviCRM SearchKit autocomplete display built for the quick search in the
[WPCV Admin](https://github.com/civicopilot/wpcv-admin) Wordpress plugin.

Licensed under [AGPL-3.0](LICENSE.txt).

## Installation

Learn more about installing CiviCRM extensions in the [CiviCRM Sysadmin Guide](https://docs.civicrm.org/sysadmin/en/latest/customize/extensions/).

## Configuration

The extension creates the **WPCV Quick Search** saved search and its autocomplete display. You can edit them from the default to adjust search fields and result formatting.
